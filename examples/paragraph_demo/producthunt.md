# LaunchPack

**Tagline:** LaunchPack is a free tool that turns any GitHub repo into ready launch posts.

LaunchPack is a free tool that turns any GitHub repo into ready launch posts. It reads your readme and writes posts for over 100 platforms in seconds. It works fully offline with no API key, and it never invents features.

**What it does:**
- Reads your readme and writes posts for over 100 platforms in seconds
- Works fully offline with no API key, and it never invents features
